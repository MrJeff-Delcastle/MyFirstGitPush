# Student Cheat Sheet: Using GitHub and Codespaces for Team Projects 

Follow these steps to collaborate effectively with your team. 

Team Leads:

Create a index.html page.

STEP 1: Commit Your Changes 

1. Save your work. 
2. Click the Source Control icon on the left. 
3. Enter a short commit message (e.g., 'Added about page HTML'). 
4. Click ✔ Commit. 
 
Or run in terminal: 
git add . 
git commit -m "Your message here" 

STEP 2: Push Your Code to GitHub 

After committing, send your changes to GitHub: 
GUI: Click the 3-dot menu → Push 
CLI: git push origin main 

STEP 3: Pull the Latest Code 

Always pull updates before working: 
GUI: 3-dot menu → Pull 
CLI: git pull origin main 
 
If conflicts appear, open the file, fix the conflict, save, then commit and push again. 

STEP 4: Best Practices 

✅ Pull before editing 
✅ Make small, frequent commits 
✅ Write clear commit messages 
✅ Communicate with your team
